# SIEM Implementation and Log Analysis

## Objective

My objective for this lab was to setup an Active Directory environment that I can practice performing and detecting cyber attacks! My main focus was to ingest and analyze logs within a SIEM to see what common attacks look like in the real world. To generate telemetry I used a mixture of manually performed attacks, and also Atomic Red Team test scripts to mimic various MITRE ATT&CK Framework TTPs. This home-lab was aimed to deepen my understanding of analyzing attack patterns, network security, and defensive strategy.

### Skills Learned
- Advanced understanding of SIEM concepts, configuration, and practical application
- Proficiency in analyzing and interpreting network logs.
- Ability to generate and recognize attack signatures and patterns.
- Enhanced knowledge of network protocols and security vulnerabilities.
- Development of critical thinking and problem-solving skills in cybersecurity.
- Improved skills mapping MITRE ATT&CK framework to known attacker's TTPs
- Improved knowledge of network configuration and network data flow

### Tools Used
- VirtualBox as a type 2 hypervisor
- Splunk as a SIEM along with universal forwarders
- Wireshark for capturing and examining network traffic.
- AtomicRedTeam atomic test scripts to generate MITRE ATT&CK telemetry

### Machines Involved
- Splunk Server Installed on Ubuntu 24.04.4
- Active Directory DC on Windows Server 2022 (Splunk Universal Forwarder & Sysmon Installed)
- Target machine is a Windows 10 host (Splunk Universal Forwarder & Sysmon Installed)
- Attacker machine is a Kali Linux host
